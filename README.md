# 轻画布

可双击打开的本地 AI 节点画布。当前版本 2.3.4。

代码仓库：https://github.com/xdminx0x/light-canvas

## 使用

1. 下载项目或克隆仓库。
2. 使用 Chrome 或 Edge 打开“index.html”。
3. 在项目内新建或选择 `data` 文件夹，保存画布、图片与 API 配置。
4. 在设置里填写这台电脑使用的供应商、模型和 API 密钥。

仓库不含任何用户画布、图片或 API 配置。桌面旧版已配置的用户，可选择原来的“画布数据”文件夹继续使用。数据文件夹保存原图及密钥，请勿上传。

## 修改与构建

- 修改src/client-readable.js、client.css、browser-backend.js 等源码。
- 使用 Python 3 执行：

```sh
python src/rebuild.py
```

构建无需联网。重新打开 HTML 检查效果，将源码、生成的 HTML 和更新日志一起提交。不要在 HTML 内嵌个人数据或配置。

## 开发检查

安装 Node.js 和 Python 3，然后：

```sh
cd src
npm install
npx playwright install chromium
npm test
```

测试使用临时数据和模拟接口，完成后删除临时数据，不调用付费 API。也可设置 LC_BROWSER 使用已有 Chrome/Edge。

## 换电脑继续修改

先克隆仓库；每次修改前拉取更新，修改后构建、检查并提交推送。API 配置在各台电脑单独填写。需要迁移画布时，另行私下复制数据文件夹；Git 不负责同步画布。

变更记录见“CHANGELOG.md”，实现约束见“MAINTENANCE.md”。

## 鼠标操作

- 左键在空白处拖动：框选节点。
- 按住鼠标中键拖动：移动画布；也可使用 Space + 拖动。
- 拖动节点标题栏：移动节点。
- Shift + 点击：多选；捏合或 Ctrl + 滚轮：缩放。

## 更新流程

每次更新递增 `src/package.json` 中的版本号，并更新本说明中的当前版本及 `CHANGELOG.md`；涉及操作或维护变化时同步修改说明。重新构建 HTML、完成检查后，通过 Git/GitHub CLI 提交并推送。用户数据与密钥不得加入 Git。

## 永久删除历史图片

生图历史中，每张图片右上角的垃圾桶可永久删除该图。确认后会删除原图、调整后的副本、缩略图和对应数据记录，并移除所有画布及历史请求对该图的引用。同一次生成的其他图片会保留；最后一张图片删除后，该次记录也会移除。删除无法撤销，撤销操作不能恢复；外部备份和已下载的副本不受影响。

## 查看原尺寸图片

在图片结果中点击生成的大图，会在独立窗口中先按窗口大小适应显示。点击图片切换到原始分辨率，可滚动查看；再点一次恢复适应窗口。支持键盘聚焦后按 Enter 打开。若没有打开，请允许浏览器弹出窗口。

图片结果浮层可点击外侧空白区域关闭；点击图片、提示词或其他内容不会关闭。从生图历史打开的结果关闭后会返回图库。

## 图生图参考图片

图生图输入框中的 `@` 只列出直接连接到该节点的图片，以及节点自身附带的图片。其他图片节点不会出现；先连接参考图，再使用 `@`。模型选择列表按版本由新到旧排列，同版本日期快照由新到旧排列，默认别名排在对应快照前；已有节点选中的模型保持不变。

## Windows / Edge 首次连接 data

先打开本机 index.html，点击“选择数据文件夹”，选中项目里的 data 后点击“选择文件夹”，并允许浏览器查看和编辑。空 data 会自动初始化，不需要手工创建 canvas.json。若“临时打开”能进入、但 data 没有生成文件，请查看页面底部的授权或写入错误；不要只创建文件夹而跳过浏览器授权。若设备由组织管理，文件访问可能受浏览器策略限制。

## 节点排列

生成结果与提示词之间的连线会在等待图片时显示，缩小画布也保持清晰；结果节点位于当前可视范围之外时，连线仍指向该节点。

节点右上角的“引用到其他节点”按钮及 C 快捷键已移除。参考图片仍可通过左右端口拖线连接，或使用“继续生图”。节点编辑只保留当前提示词，撤销/重做画布操作不会恢复旧提示词；生图历史保留每次实际发送的提示词。

点击提示词框不会再改变文字内边距；拉高输入框、滚动长文本和缩放画布后也使用相同定位。重新连接单张参考图会恢复它的参考状态；能确认是一对一替换时同步旧编号，多图关系不明确时仍需手动确认编号。

粘贴图片时，把鼠标放到画布上的目标位置，首个节点左上角会落在鼠标处；多张图片从该位置向右排列，视图不会自动跳动。复制生成结果或参考图片后再粘贴也一样。通过菜单粘贴时使用鼠标最近在画布上的位置；尚未定位过鼠标时回退到视图中心。

画布顶部操作面板已移除。新建输入、导入/粘贴图片、撤销/重做等操作收在右上角的“画布操作”菜单，快捷键继续可用。双击空白处或按 N 新建输入。

默认启用拖动吸附：靠近其他节点的边缘或中心时自动贴齐，显示辅助线；按住 Alt 可临时自由拖动。参考 [PureRef 邻近边缘吸附](https://www.pureref.com/handbook/images/#neighbor-snapped-move-item)，本画布按你的要求无需组合键开启。

一次请求生成多张图时，每张图独立显示为一个结果节点，可以分别连线作为参考。“复制原图”后粘贴到画布，或选中结果节点使用 Ctrl/Cmd+C、V，都会得到参考图片节点。内部粘贴引用同一原文件，发送时也读取原文件；节点预览不改变原始图片。

左键从空白处拖出选框，只要选框覆盖节点的一部分就选中，无需框住整个节点；中键按住拖动用于移动画布。

新生成的结果放在输入节点右侧，继续生图/追问的新输入放在结果右侧；右侧有节点占位时，在同一列向下避让。“整理布局”按连线将流程整理为从左到右，分支在上下展开。已有节点不会因打开新版自动移动，需要时点击“整理布局”。

### 图片比例与横向连线

连接点固定在节点标题两侧，输入内容变长也不会把连接点带到屏幕下方。

画面比例直接转换为接口原生尺寸，面板显示实际请求像素；1K/2K/4K 为近似档位，尺寸须符合模型限制。例如支持自定义尺寸的模型选择 21:9、2K 时请求 2016×864。超过限制会提示降低分辨率，不再改成其他比例或在本地放大、补边。接口返回尺寸不一致时，结果中标注差异并保留原图。旧版历史图片保持不变。GPT Image 2.6 等未确认自定义尺寸支持的型号会提示支持待接口确认，接口拒绝时显示原错误，不自动重试。

## 生图费用估算

图片结果中的“预估费用 · USD”根据所用模型与 API 返回的实际 Token 分类自动计算，无需先填写接口单价。“费用计算明细”可展开查看文本输入、图片输入、图片输出各自的用量、美元单价与费用。多图请求显示整次请求费用，不按结果张数重复乘算。

支持 GPT Image 2.6、2.5、2、1.5、1 mini、chatgpt-image-latest 及对应日期快照。内置价格为 2026-11-16 核对的 [OpenAI Standard 官方参考价](https://developers.openai.com/api/docs/pricing#images)，未套用 Batch 折扣或无法核验的缓存优惠，实际账单以供应商为准。未知模型或用量分类缺失会明确提示，不把缺失数据当成零费用。

已有记录保存了完整 Token 分类时也能立即看到估算，不重新调用 API、不改写历史数据。新请求保存当时采用的价格快照，后续更新价格表不会改变其计价依据。其他模型可沿用完整的手动 USD 输入/输出单价或每张图片价格；非美元单价不自动换算。
